# OpenUptime skill

An agent skill that teaches coding agents how to use the [OpenUptime MCP server](https://openuptime.app/docs/mcp): add
monitors, handle incidents, pause monitors for maintenance and build status pages.

```bash
npx skills add becoolme/openuptime
```

It works with the hosted service or a self-hosted server. The skill needs the `openuptime` MCP server to be connected;
see the [MCP docs](https://openuptime.app/docs/mcp) for client setup.
