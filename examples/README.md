# Examples

Setups that use OpenUptime from outside the app. Each folder stands on its own; copy the one you need.

| Folder | What it does |
| --- | --- |
| [`browser-check`](browser-check) | Signs in to a site with Playwright on a schedule in GitHub Actions and reports to a heartbeat monitor. |
| [`config-as-code`](config-as-code) | Keeps a project's monitors in a JSON file: plan on pull requests, apply from CI, the same result on every run. |
