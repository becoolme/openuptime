Know it’s down before your users do.

OpenUptime is an open-source uptime monitor that runs on Cloudflare Workers and keeps its data in your own Postgres. Multi-region checks, API-first, and no server of yours to keep alive.

Deploy to Cloudflare→ View on GitHub
$ npm create openuptime@latest

No sign-up. No telemetry. Runs in your Cloudflare account, on your own Postgres.

Deploy the Worker

One command deploys OpenUptime to your Cloudflare account. Cron Triggers run the checks, so there is no server to keep alive.

$ npx wrangler deploy
✓ deployed · cron checks on
2
01:00

Connect your Postgres

Point the Worker at any Postgres through Hyperdrive, such as Neon, Supabase or your own. Migrations run on first start.

$ wrangler secret put DATABASE_URL
✓ schema migrated
3
02:30

Add monitors and alerts, publish a status page

Paste a URL or bulk-create through the API, hook up Slack, Telegram or a webhook, then publish. The page updates itself when something breaks.

→ status.acme.dev
✓ published · custom domain
The status quo

Every option makes you compromise somewhere

What most teams want is simple: reliable alerts, a status page worth showing customers, and no vendor lock-in.

Bills that scale faster than you do

SaaS monitors charge per monitor, check interval, seat and status page. Add services and monitoring becomes a line item of its own.

1 box

A monitor that shares its fate with your servers

Self-hosted tools run on the same infrastructure they watch. When that machine or network has a bad day, the alerts go down with it.

no API

Automation without an API

New service, new monitor, more clicking. Without a complete API you can’t fold monitoring into Terraform or CI.

What you get

Monitoring, alerting and status pages in one box

All open source. There is no “enterprise only” feature wall.

Checks that go beyond a status code

HTTP, TCP, ping, DNS, TLS expiry and heartbeats as often as every minute. Assert on keywords or JSON paths, not just 200 OK.

HTTP(S)TCPPingDNSTLSHeartbeatgRPC

Multi-region confirmation

Checks run on Cloudflare’s global network, not on one machine you have to keep alive. An alert fires only when probes agree.

Status pages people trust

Custom domain and branding, incident timeline, scheduled maintenance and subscriber notifications.
